# Swite

The official dev server and compilation engine for SwissJS applications.

## What is Swite?

Swite is a zero-configuration development pipeline built natively for the SwissJS ecosystem. It handles `.ui` and `.uix` file compilation, hot module replacement, and production builds — replacing Vite entirely for SwissJS projects.

## Quick Start

```bash
npm create swissjs@latest my-app
cd my-app
pnpm install && pnpm dev
```

## Architecture

This site is built with SwissJS and served by Swite itself. Source port: 6002.
